# PropertyShare MVP
Next.js + Supabase fractional real-estate marketplace starter.

Setup: copy `.env.example` to `.env.local`, add your Supabase URL/publishable key, run `supabase/schema.sql` in Supabase SQL Editor, then `npm install && npm run dev`.

Before accepting real investments, implement compliant offering documents, KYC/AML, investor eligibility, securities-law review, payment/escrow, audit logging and secure server-side transaction handling. Never expose a Supabase service-role key in browser code.
